# Hof-Testrunde

Fragebogen zum Usability-Test von [Life's a Game](https://lazo-dot.github.io/lifes-a-game/), einer Gewohnheits-App mit Pixel-Hof. Die Seite speichert keine Antworten auf einem Server und bindet keine fremden Dienste ein; Testpersonen schicken ihre Antworten am Ende selbst per Nachricht.
